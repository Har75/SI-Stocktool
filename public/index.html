Sample research desk

SI StockTool

Search, quotes, and a Stock analyzer for case studies. Portfolio holdings are a percentage, or an encrypted share count, saved on your account. Live calls go through this server to Alpha Vantage. Your key stays in this browser tab.

Account

Log in for an existing account. New account opens a separate sign-up page. Passwords are at least 10 characters. The server stores only a hash and keeps the browser session in an HTTP-only cookie.

New account

Upgrade

Pro is required for Stock Analyzer and the watchlist. Upgrade opens Stripe Checkout; canceling the subscription, or a failed payment, sets the plan back to Free.

Connection

Paste an Alpha Vantage key for live search, quotes, and scoring. It stays in this browser tab; public hosting does not fall back to a server key, and the key is not written to logs.

Portefeuille

Posities staan op je account. Standaard kies je een percentage van de portefeuille, zonder het totale bedrag te noemen. Percentages mogen samen minder dan 100% zijn. Meer dan 100% wordt geweigerd. Een aantal aandelen wordt in deze browser versleuteld met AES-GCM en een portefeuille-PIN. De server bewaart alleen de cijfertekst. Er is geen herstelsleutel: raak je de PIN kwijt, dan zijn de aantallen niet terug te halen. Een reset van het accountwachtwoord herstelt ze ook niet, omdat dat wachtwoord niet de sleutel is.

Log in om posities toe te voegen. Ze blijven op je account staan. Pro is niet nodig voor de portefeuille zelf.

    Search

    Search asks Alpha Vantage for symbols that match a company name or ticker. The matches are lookup results, not a recommendation.

      Live quotes

      Live quotes are the latest prices Alpha Vantage returns for the tickers you enter. Prices can be delayed or missing, and one request can include at most 20 tickers.

        Stock Analyzer

        Stock Analyzer scores one ticker on eight teaching pillars, from a live Alpha Vantage snapshot or from the replay case for a sample ticker. The composite averages the pillars that have data and is not a buy or sell view.

        Stock Analyzer is available on the Pro plan and to admin accounts. Log in and upgrade to score a ticker.

          Add to watchlist?

          Watchlist

          The watchlist stores tickers you save after a score, with the latest composite, the previous composite, when it last ran, and an optional note. Re-score runs only when you ask, using the Alpha Vantage key from this browser.

          The watchlist is available on the Pro plan and to admin accounts. Log in and upgrade to save tickers.
